# Shinning Star

Multipage company website. The complete static website is in `dist/`. Upload the contents of `dist/` to your web host. No build step is required.

Live preview: https://shinning-star-creative.odabkl.chatgpt.site

Includes the interactive experience constellation, company logo, event photography and company profile. The contact planner downloads a brief; WhatsApp and Gmail contact setup is pending the company's contact details.

GitHub stores this source copy. Changes here do not automatically deploy to the Sites preview.
